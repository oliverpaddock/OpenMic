# OpenMic
An open-source audio interface

## About
OpenMic is an open-source, 2-in/2-out, usb-c audio interface with the following features:

- Combo XLR/TRS inputs for mic/line/instrument in
- Digitally-switched resistor gain network
- 51dB analog gain (mic)
- -12dB to +12dB analog gain (line and instrument)
- Handles line inputs up to +24.5dBu
- 48V phantom power
- Direct monitor switch
- Stereo balanced line output
- Stereo headphones out, drives 32ohm to 600ohm headphones
- ~18dBu max output
- USB-C bus-powered (1.5A) with PD external power fallback
- Up to 32-bit/96kHz audio

The design uses the TAC5212 (119dB ADC dynamic range, 120dB DAC dynamic range) audio codec and an XU316 as the main controller.
